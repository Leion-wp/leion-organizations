# Leion Organizations

Modèles déclaratifs réutilisables pour Leion Studio. Copiez un modèle dans votre workspace privé et personnalisez ses missions avec CAPS. Les modèles décrivent une organisation ; les permissions et secrets actifs appartiennent au runtime privé.

`schemas/graph-v1.schema.json` est le contrat versionné. `templates/` contient les exemples Sécurité et Création de contenu avec leurs exports Mermaid.
